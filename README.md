# quadratic-plugin

A sample plugin implementing agentic capabilities for GitHub.

## Structure

- **`plugin.json`** - Plugin manifest with metadata and configuration
- **`agents/`** - Agent definitions for Copilot
- **`skills/`** - Skill definitions for the plugin
- **`hooks.json`** - Hook configurations
- **`.mcp.json`** - MCP server configuration
